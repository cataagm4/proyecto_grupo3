# Proyecto Grupo 3



## Descripción

En este primer laboratorio, empezamos a aplicar conceptos basicos de git en un repositorio	 en grupo. Utilizamos clonación del repositiorio requests de pull , commits y demás comandos basicos. Adicionalmente se realizó también un informe.



## Comandos utilizados y su propósito



| Comando | Propósito |

|--------|-----------|

| `git config --global user.name "Nombre"` | Configurar nombre de usuario para commits |

| `git config --global user.email "email"` | Configurar correo electrónico para commits |

| `git clone <url>` | Clonar el repositorio remoto |

| `git add .` | Agregar todos los archivos al área de staging |

| `git commit -m "mensaje"` | Crear un commit con los cambios |

| `git push origin <rama>` | Subir cambios a GitHub |

| `git checkout -b <rama>` | Crear y cambiarse a una nueva rama |

| `git merge <rama>` | Fusionar una rama a la actual |

| `git pull origin <rama>` | Traer cambios del remoto |

| `git revert <commit>` | Deshacer un commit de forma segura |

| `git branch -a` | Listar todas las ramas |
